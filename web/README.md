# WHEELTEC Web 实验控制台使用说明

## 启动

开发调试：

```bash
cd turn_on_wheeltec_robot/web
npm install
npm run dev
```

机器人运行时建议通过 ROS 启动 Web 服务：

```bash
roslaunch turn_on_wheeltec_robot web_control.launch start_base:=false start_current_reader:=false start_data_collector:=false
```

浏览器访问 `http://<robot_ip>:8000`，rosbridge 默认连接 `ws://<robot_ip>:9090`。

## 页面区域

- 连接工具条：配置 rosbridge 地址、IMU 话题、连接/断开、急停和释放。
- 驾驶控制：手动摇杆、巡航方向/速度、航向角控制。
- 实验任务向导：选择实验类型、故障轮、衰减系数、run ID、采集时长和期望频率。
- 数据采集：配置输出目录、电流板端口，开始/停止采集，查看最近 CSV 文件。
- 故障注入：手动应用或重置 A/B/C 轮目标速度衰减。
- 数据可视化：查看实时曲线，或选择 CSV 文件进行回放预览。
- 采集质量检查：查看采样率、电流板状态、运行时长和质量等级。
- 数据集统计：按故障类别统计 CSV 数量、run 数、总行数和总时长。
- 数据集构建：将 CSV 构建为训练/测试 NPY 数据集。

## 推荐实验流程

1. 启动底盘、rosbridge、Web 控制服务，并在页面点击连接。
2. 确认电流板端口、输出目录、期望频率。
3. 在实验任务向导选择实验类型。驱动异常实验可选择 A/B/C 故障轮和 alpha 衰减系数。
4. 输入 run ID，或留空使用自动生成的 ID。
5. 设置采集时长，点击“开始实验”。控制台会自动应用故障配置、启动采集和倒计时。
6. 采集过程中观察实时曲线和采集质量检查。
7. 停止后刷新文件，选择 CSV 预览曲线，确认数据无明显断流或异常。
8. 数据量足够后进入数据集构建区域，生成训练数据集。

## 文件与可视化

CSV 文件列表固定在“最近 CSV 文件”区域内滚动，文件很多时不会挤压故障注入或数据集构建模块。点击“预览”会调用 `/api/data/preview`，后端只返回抽样数据点，避免大文件一次性加载造成页面卡顿。

实时曲线默认保留最近约 180 个点，包含电流 A/B/C、电压、里程计速度和 IMU Z 轴角速度。

## 质量指标

质量检查会综合以下信息：

- 采集状态和 CSV 行数。
- 运行时长与估算采样率。
- 估算采样率相对期望频率的偏差。
- 电流板连接状态、最近电流帧延迟和有效帧数。
- data_collector 状态中的错误信息。

质量等级用于现场提示，不替代离线数据验证。正式训练前仍建议检查 CSV 预览和数据集统计。

## 安全注意事项

- 开始实验前确认机器人周围安全，必要时先降低速度倍率。
- 急停会停止手动和巡航命令，恢复前确认故障注入和采集状态。
- 采集中尽量不要切换输出目录、run ID 或故障类型。
- 电流板离线或电流延迟过高时，不建议继续采集训练数据。
- 故障注入实验结束后点击重置，避免下一次正常实验带着故障配置运行。
